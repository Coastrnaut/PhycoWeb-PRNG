# Contract: Reference Model API (`phycoweb`)

## `phycoweb.model.PhycoWebEngine`

```text
PhycoWebEngine(seed: Sequence[int])     # len(seed) >= 4 and seed[0..3] each int in 0..65535, else ValueError
  .compute_block() -> int               # one step; returns unsigned 32-bit word (0 … 2**32-1)
  .step_count -> int                    # number of compute_block() calls so far
```

- Deterministic: the same seed always gives the same sequence (Principle V).
- The module imports nothing beyond `phycoweb.lut` and `typing`: no `math`, `numpy`, or
  floating point (FR-002). An AST test enforces this.
- `MODEL_ID = "lut-v1"` is exported for use in vector and report metadata.

## `phycoweb.lut`

```text
PERTURBATION_LUT: tuple[int, ...]       # 256 entries, each 0 … 0xFFFF
LUT_BITS = 8                            # table length = 1 << LUT_BITS
INC_A = 4
INC_B = 6
COS_OFFSET = 64
```

- Generated by `scripts/gen_lut.py`, never edited by hand (header comment says so).

## Archived baseline adapter (vector tool only)

`scripts/gen_vectors.py --model float-v0` loads `baseline/float-v0/readmee_model.py` as a module
from its file path, without modifying it, and masks each output `& 0xFFFFFFFF` (research R2).
