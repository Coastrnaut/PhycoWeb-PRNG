# Contract: `sp80022` package (harness)

Pure functions over a bit array. It does not depend on `phycoweb`.

## Input

`bits`: 1-D `numpy.ndarray` of `int8` or `uint8` with values in {0, 1}. Functions never modify
their input; a test asserts this (lesson from N2). Inside each function, counts use `int64`
(lesson from N1).

## Per-test functions

`sp80022.tests.<name>(bits, **params) -> TestResult`

```text
TestResult = { name: str, eligible: bool, p_values: list[float], params: dict, stats: dict }
```

| `name` | `len(p_values)` when eligible |
|--------|------------------------------|
| `frequency`, `block_frequency`, `runs`, `longest_run`, `rank`, `dft`, `overlapping_template`, `universal`, `linear_complexity`, `approximate_entropy` | 1 |
| `cumulative_sums` | 2 (forward, reverse) |
| `serial` | 2 |
| `random_excursions` | 8 (x = −4…−1, +1…+4) |
| `random_excursions_variant` | 18 (x = −9…−1, +1…+9) |
| `non_overlapping_template` | 148 (template order from `templates(9)`) |

- Default `params` are the values in research R2. Passing other values is allowed for unit
  tests (worked examples use small n). The evaluator always uses the defaults and records them.
- If a sequence is not eligible (for example J < 500 for the excursion tests, or n is too short),
  the result has `eligible = False` and `p_values = []`. It never raises.
- `stats` holds the intermediate values the SP 800-22 worked examples print (χ², J, W, …), so
  the tests can check them as well as the p-value.

## Battery and aggregation

- `sp80022.battery(bits) -> list[TestResult]`: all 15 tests in SP 800-22 order. Each test gets a
  fresh read-only view.
- `sp80022.templates(m) -> list[str]`: the aperiodic templates in increasing numeric order.
- `sp80022.assess(per_sequence: list[list[TestResult]]) -> Assessment`: proportion, uniformity,
  q(m′) and k_max for each sub-test and family, and the overall pass flag (research R4).
- `sp80022.__version__`, and `sp80022.source_sha256()`: a hash over the package's `.py` files,
  sorted by path, with LF line endings.

## Guarantees

- Deterministic: the same bits give the same `p_values` (no randomness anywhere).
- p-values are floats in [0, 1]. A test that SP 800-22 says "fails by definition" (Runs
  prerequisite) returns 0.0.
